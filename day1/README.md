## Day 1 — Linux 상태 확인

**티켓:** “서버가 느리다는 제보가 들어왔다. 먼저 현재 상태를 확인해 주세요.”

- 학습: 프로세스, 메모리의 available, 디스크 사용률, systemd 상태. [Ubuntu 서버 가이드](https://documentation.ubuntu.com/server/)
- 실습: VM에서 `uptime`, `free -h`, `df -h /`, `systemctl --failed`의 의미를 이해하고 실행한다. 결과 해석에 집중한다.
- 검증: 각 결과가 무엇을 뜻하는지와 현재 주의할 항목을 기록한다. 한 번의 관찰만으로 장애가 없다고 단정하지 않는다.
- 질문: 메모리의 free와 available은 왜 다른가?
