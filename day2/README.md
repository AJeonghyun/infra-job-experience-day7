## Day 2 — 네트워크 경로

**티켓:** “웹페이지가 열리지 않는다. 어디서부터 확인해야 할까?”

- 학습: IP, DNS, TCP 포트, HTTP 응답. [MDN HTTP 개요](https://developer.mozilla.org/en-US/docs/Web/HTTP/Guides/Overview)
- 실습: VM에서 `ip addr`, `getent hosts example.com`, `ss -lnt`, `curl -I https://example.com`을 확인하고 결과를 해석한다.
- 검증: DNS 조회와 HTTP 요청 중 실패한 단계가 있으면 구분해 기록한다. IP와 포트는 공유 전 가린다.
- 질문: 이름 해석이 성공해도 웹 요청은 왜 실패할 수 있을까?
