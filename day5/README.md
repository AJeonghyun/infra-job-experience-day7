## Day 5 — AWS 구성 이해

**티켓:** “외부에서 접근할 테스트 웹 서버를 AWS에 배치한다면?”

- 학습: EC2, VPC, 서브넷, 라우팅, 보안 그룹. [EC2 시작하기](https://docs.aws.amazon.com/AWSEC2/latest/UserGuide/EC2_GetStarted.html)
- 실습: 브라우저 → 인터넷 → VPC → EC2 → Nginx 흐름을 그린다. 필요한 인바운드 접근과 관리 접근을 구분한다. 관리 포트를 전체 인터넷에 무제한으로 열지 않는다.
- 선택: 계정·요금·보안을 준비한 경우에만 EC2를 만들고 접속을 확인한다. 실습 후 리소스를 정리한다.
- 검증: 직접 실행한 것과 설계만 한 것을 분리한다. 리소스 및 비용 확인 방법을 기록한다.
- 질문: 서버의 서비스가 정상이어도 보안 그룹 때문에 접속이 막힐 수 있는 이유는?
