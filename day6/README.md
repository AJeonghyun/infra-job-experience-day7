## Day 6 — 운영 점검과 인수인계

**티켓:** “다음 담당자도 서버 상태를 같은 순서로 확인할 수 있게 해 주세요.”

- 학습: 운영 절차서(runbook)의 목적과 종료 상태.
- 실습: Day 1~5에서 직접 쓴 확인 순서를 서비스 상태 → 포트 → HTTP 응답 → 로그 순으로 정리한다. 여유가 있다면 한 항목을 셸 스크립트로 직접 작성한다.
- 검증: 절차를 따라 정상 상태를 확인한다. 스크립트를 작성한 경우 정상과 서비스 중단 상태에서 결과를 비교하고 복구한다.
- 질문: 명령 하나가 실패했을 때 담당자는 다음에 무엇을 확인해야 하는가?
