## Day 3 — Nginx 서버와 장애 복구

**티켓:** “테스트 서버에 상태 페이지를 띄워 주세요.”

- 학습: 패키지, systemd 서비스, 포트 80, HTTP 응답. [Ubuntu Nginx 가이드](https://documentation.ubuntu.com/server/how-to/web-services/install-nginx/)
- 실습: 테스트 VM에 Nginx를 설치하고 `systemctl status nginx`, `ss -lnt`, `curl -I http://127.0.0.1`로 상태와 응답을 확인한다. 설치 과정은 직접 조사한다.
- 검증: 서비스 상태, 수신 포트, HTTP 상태 코드를 기록한다. 테스트 VM에서 서비스를 중지하고 증상과 상태를 확인한 뒤 복구하고 재확인한다. 시간이 부족하면 중단·복구를 별도 블록으로 나눈다.
- 질문: 서비스가 실행 중이어도 클라이언트가 접속하지 못하는 이유는?
